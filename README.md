# 🔐 Simple Python Tkinter Password Manager

A minimal and lightweight password manager built using **Python** and **Tkinter**.  
This project is designed to securely store and manage your passwords in a simple desktop GUI application.

---

## ✨ Features

- Clean Tkinter-based graphical interface
- Add, view, and manage saved passwords
- Lightweight and fast
- Cross-platform support (Windows & Linux/macOS)

---

## 📦 Requirements

- Python 3.9 or higher
- pip (Python package manager)

If dependencies are required, install them using:

```bash
pip install -r requirements.txt
```

## 🛠 Build Instructions

This project includes platform-specific build scripts.

### Windows

Run the following:
```bash
build.bat
```

### Linux / macOS

Run the following:
```bash
chmod +x build.sh
./build.sh
```

### 📁 Build Output

After a successful build:
- The compiled executable will be located inside the ``dist`` folder.

### ▶️ Running the Application (Without Building)

Alternatively you can also run the project directly with Python:
```bash
python main.py
```

## 📌 Notes

- Make sure Python is added to your system PATH.

- If the build fails, verify all dependencies are installed correctly.

- The dist folder is generated automatically during the build process.
